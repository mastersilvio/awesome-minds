# Awesome Minds

Um catálogo colaborativo de pessoas que transformaram a maneira como entendemos, criamos e vivemos no mundo. O projeto reúne suas ideias, descobertas e contribuições com contexto histórico e fontes para quem quiser se aprofundar.

## O que você encontrará aqui

Perfis de pensadores, cientistas, artistas, inventores e outras pessoas de diferentes épocas e lugares. Cada perfil deve explicar, em linguagem clara:

- quem foi a pessoa e em que contexto viveu;
- quais foram suas principais contribuições;
- por que essas contribuições tiveram impacto;
- onde verificar as informações e continuar a leitura.

## Perfis

- [Isaac Newton](perfis/isaac-newton.md) — leis do movimento, gravitação e óptica.
- [Leonardo da Vinci](perfis/leonardo-da-vinci.md) — pintura, estudos de anatomia e engenharia.

## Critérios de inclusão

“Brilhante” é uma avaliação subjetiva. Para manter a seleção transparente, cada indicação deve apresentar uma contribuição identificável, explicar seu impacto e citar fontes confiáveis. O projeto busca diversidade de áreas, culturas e períodos históricos e aceita revisões quando surgirem evidências melhores.

## Como contribuir

Abra uma issue para sugerir uma pessoa, corrigir uma informação ou discutir uma fonte. Para adicionar ou revisar um perfil, envie um pull request com referências e uma explicação breve das mudanças. Evite atribuir uma descoberta a uma única pessoa quando ela resultar de trabalho coletivo.
